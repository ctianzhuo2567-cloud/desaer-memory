# Paper & Ink · 档案纸墨（自定义主题）

按 theme-factory 的自定义主题格式定义。方向：简约、高级、现代；设计叙事是「产品档案 / dossier」——索引式行、细线、克制的标注。

## Color Palette

- **暖白纸 Paper** `#fafaf9`：页面背景
- **墨 Black Ink** `#191917`：正文
- **强调蓝 Accent** `#2563eb`：主操作、选中态、今日数字
- **次级灰 Secondary** `#6f6d67`：辅助文字
- **细线 Hairline** `#e9e7e1`：分隔
- **成功绿** `#15803d`：答对、掌握
- **失败红** `#c62828`：答错、错题

## Typography

- 全站单一字体族：系统无衬线（PingFang SC / Microsoft YaHei），不使用衬线/宋体
- 数字与产品代号：`tabular-nums` 等宽数字对齐
- 层级：超大数字 64px 作为视觉锚点，标题 18–20px / 700，正文 15px，辅助 12–13px，字距克制

## 签名元素

首页的超大「今日数字」（待复习或今日新卡数），作为唯一的大字号视觉锚点；完成态以同字号的「✓」替换。

## Best Used For

简洁高级的工具类移动端界面：记忆、清单、数据查阅、档案型信息产品。
