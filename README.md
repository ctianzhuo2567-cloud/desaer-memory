# 百品记

面向手机的皮革化学品产品记忆应用：像背单词一样翻卡记忆，支持间隔重复复习、错题本、按产品名称搜索和完整产品详情。

## 直接使用

这是一个 PWA（渐进式网页应用），构建产物都在本目录：

- `index.html` —— 整个应用（约 465 KB），界面、逻辑与 259 个产品数据都在这一个文件里。
- `manifest.webmanifest`、`sw.js`、`icon-*.png`、`apple-touch-icon.png` —— 安装到主屏与离线运行所需。

- **电脑**：双击 `index.html`，用浏览器打开即可。
- **安卓手机**：单独打开本地 `index.html` 也能用，但没有图标、全屏和离线，推荐用下面“放到网上”的方式。
- **iPhone**：iOS 不能直接打开本地 HTML，请用“放到网上”的方式。

### 放到网上并安装（推荐，手机体验最好）

把本目录这些文件上传到任意静态托管（GitHub Pages、Vercel、Netlify、Cloudflare Pages、腾讯云 COS 等），然后：

- **安卓（Chrome/Edge）**：打开网址，菜单里点“安装应用”或“添加到主屏幕”，主屏出现“百品记”图标，全屏运行、可离线。
- **iPhone（Safari）**：打开网址，点分享按钮 → “添加到主屏幕”，iOS 会把它当作独立应用运行。

注意：GitHub Pages 免费版、Vercel、Netlify 的站点都是公开链接，知道网址的人都能打开。如果产品说明书内容不宜公开，用 Cloudflare Pages + Cloudflare Access（免费版支持 50 人，邮箱验证码登录）或自建带密码的托管。

### 局域网方式（不联网也能用）

电脑和手机连同一个 WiFi，在电脑上本目录运行：

```powershell
python -m http.server 8000
```

手机浏览器访问 `http://电脑IP:8000/`。这只适合临时预览：普通局域网 IP 没有 HTTPS，不能离线，也无法真正安装成 App；正式使用请用上面“放到网上并安装”的方式。

## 功能

- **学习**：点击「开始今天的学习」进入完整流程。先翻卡学习当天的一批新产品（数量为“每日新产品数”，当天固定、顺序随机）：忘记/模糊的卡片会在本轮末尾重新出现，认识（首次隔 1 天、之后隔 7 天复习）/掌握（隔 7 天）则通过；翻卡不会记入错题本。学习完成后自动进入同一批产品的答题。
- **答题**：与当天学习同一批产品、同样数量，顺序随机；昨天的错题排在最前。答完即时判对错并自动进入下一题，一轮结束后错题集中重考一次；答对不影响“学习中”统计。
- **错题本**：只有答题答错会进入错题本；错题在次日答题中自动重考，累计答对 3 次即算掌握并移出。
- **专项答题**：每天按项目生成题目，选择题（类型/主要成分/外观/固含量，每产品 1 题）在前，类型判断题约一半产品数在后（错误项取相近类型）；答完显示得分，项目详情可查看近 7 天成绩。
- **产品库**：按工段分类浏览全部 259 个产品。
- **搜索**：按产品代号或中文名搜索（例如 `DESOAGEN KF`、`德赛精 KF`）。
- **详情**：主要成分、特点/性能、规格指标（颜色、固含量、离子性、pH 等）、适用工段与应用工艺、运输与储存、安全须知；颜料膏产品附颜色系列表。
- **竞品与备注**：说明书中没有竞品信息，详情页里可以自己补充，保存在本机。
- **进度备份**：“我的”里可导出/导入学习进度，换手机时先导出再导入。

## 数据说明与已知问题

数据由 [tools/extract_pdf.py](tools/extract_pdf.py) 从《德赛尔产品说明书》（2025 版，272 页 PDF）自动提取，共 259 个产品，已按目录逐条核对。以下为原文本身的瑕疵，提取时按正文页为准保留：

- 目录把 `DESOAGEN DA-L` 误写为 `DESOSSE DA-L`、把 `DESOAGEN EI` 误写为 `DESOBATE EI`，正文页是正确的。
- 丙烯酸树脂、聚氨酯树脂等部分页面的文字层有较多 OCR 式错字（例如“聚氨酯分散液”被写成“聚氧酯分数液”），不影响结构，但个别字需要人工校对。
- 说明书不含竞品信息，竞品字段默认留空，可在应用内自行补充；也可以给我一份竞品对照表，我批量写进数据。

## 更新数据或修改应用

提取脚本和构建脚本都是可重复执行的：

```powershell
$py = "C:\Users\user\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe"
& $py tools\extract_pdf.py "<产品说明书.pdf路径>" data\products.json
& $py tools\build_app.py data\products.json app .
```

- 界面与逻辑在 `app/template.html`，PWA 配置在 `app/manifest.webmanifest` 和 `app/sw.template.js`，改完重新执行构建即可。
- 每次构建自动生成内容哈希版本号，显示在“我的 → 版本”；service worker 凭它自动让手机切换到新版本。
- `tools/smoke_test.js` 用本机 Chrome 跑主流程冒烟测试，`tools/pwa_check.js` 验证安装与离线，改完构建后建议都跑一遍。

### 更新而不丢手机上的进度

- **界面/逻辑更新**：重建后覆盖到同一个网址即可。学习进度存在浏览器 localStorage（键 `desaar_memory_v1`），与 HTML 文件无关，同一网址下自动保留。
- **产品数据更新**：产品 id 就是产品代号本身（不含页码），换新版 PDF 重新提取不会改变 id，旧进度继续有效。
- **不要动 `dataEpoch`**：`app/template.html` 里的 `dataEpoch` 只在产品 id 体系发生变化时才允许提高；提高它会清空所有学习进度。
- **换手机/浏览器/网址**：先在“我的”里导出进度 JSON，再到新环境导入。
- 手机长期不访问时浏览器可能回收存储；装成 PWA 后风险更低，但仍建议定期导出备份。
